# Ethnic Community Media and Audience Trust in America

Research from MIDAS Lab, Walter Cronkite School of Journalism and Mass Communication,
Arizona State University.

## Website

The homepage is `index.html`. It introduces four areas of research, with expandable
project descriptions, publication references, and PDF downloads.

The interactive atlas is `mapping-ethnic-media-2025.html`. Its data and map geometry
are embedded in the page. The current source data is `ethnicmedialist.csv`.

## Hosting and updates

This is a static website. GitHub Pages can publish the `main` branch from the root
folder. No build tools or server are required. Keep the files together when uploading
or updating them, because links use relative paths.

To view locally, open `index.html` in a browser. Updates pushed to `main` are published
automatically after GitHub Pages is enabled.
